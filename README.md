# worklore research

Experiments behind [worklore](https://worklore.dev) stories and articles: what was measured, the scripts that measured it, and the reports. Each folder is one experiment, named by the date it started.

- [`2026-10-03-story-eval`](2026-10-03-story-eval/) (see the folder)
- [`2026-10-06-dev-showcase`](2026-10-06-dev-showcase/) What developers show in public, and does it pay? (sketch, 2026-10-06)
- [`2026-10-06-devto-sites`](2026-10-06-devto-sites/) What dev.to authors show on their own sites (2026-10-06)
- [`2026-10-06-mcp-scan`](2026-10-06-mcp-scan/) MCP checkup sample — 2026-10-06
- [`2026-10-07-tool-count`](2026-10-07-tool-count/) Does the number of MCP tools hurt an agent? Measured from 5 to 100 tools
- [`2026-10-08-mcp-tool-advice-survey`](2026-10-08-mcp-tool-advice-survey/) (see the folder)
- [`2026-10-14-paste-hash`](2026-10-14-paste-hash/) (see the folder)
- [`2026-10-27-privacy-checks`](2026-10-27-privacy-checks/) Privacy checks pilot (2026-10-27)
- [`2026-10-30-canary-read-back`](2026-10-30-canary-read-back/) Canary read-back of the MCP log, 2026-10-30
- [`drafts`](drafts/) (see the folder)

Kept out of this repo on purpose (see `.gitignore`): raw agent runs and lane logs (large, and an agent's shell can print environment it should not), lists of people collected from public profiles, and screens of companies' docs while the conversation with them is open.

The guide-eval rounds live in [worklore-mcp/research/guide-eval](https://github.com/worklore/worklore-mcp/tree/main/research/guide-eval). The fake keys in `2026-10-30-canary-read-back` are canaries, invented for the test; none of them was ever valid.

Until 2026-11-02 these folders were part of the private worklore repo.
